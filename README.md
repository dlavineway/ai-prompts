# AI Prompts Repository

This repository contains a curated collection of prompt engineering resources and prompt templates for various AI-powered tools and applications. Each file in the repository focuses on a specific domain or use case, providing actionable prompts to enhance productivity, creativity, and decision-making.

## Repository Structure

- **CareerArchitect.md**: Prompts and strategies for career planning, job search, and professional development.
- **CompensationAnalyst.md**: Prompts for compensation analysis, salary benchmarking, and pay equity insights.
- **DocuMorph.md**: Prompts for document transformation, summarization, and content adaptation.
- **LyraAiPrompter.md**: Prompts for creating and refining user prompts for large language models (LLMs).
- **OrganizationalAnalyst.md**: Prompts for organizational analysis, business strategy, and process improvement.
- **PhaseN.md**: Prompts for guiding Product Managers through creating high-quality Phase N Close-Out Summaries for integrations and projects, including structured templates and stakeholder-ready documentation.
- **ThePresenter.md**: Prompts for presentation creation, storytelling, and effective communication.

## Usage

1. Browse the markdown files to find prompts relevant to your needs.
2. Copy and adapt prompts for use with your preferred AI tools (e.g., ChatGPT, Copilot, Claude).
3. Customize prompts to fit your specific context or application.

## Contributing

Contributions are welcome! To add new prompts or domains:
